# Documentação do Sistema FIEAM

## Propósito

Esta pasta é a fonte de verdade documental do Sistema FIEAM, uma aplicação interna de conscientização em segurança da informação, campanhas educativas controladas e acompanhamento de treinamentos.

O conteúdo foi estruturado segundo a persona ArchRefiner - requisitos, arquitetura, análise de impacto e planejamento. A documentação descreve o estado real observado no projeto e separa explicitamente a arquitetura atual da arquitetura-alvo.

## Regra de manutenção

Qualquer mudança de comportamento, contrato de API, persistência, integração, regra de segurança ou fluxo de usuário deve atualizar a documentação correspondente na mesma alteração.
