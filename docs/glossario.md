# Glossário do Sistema FIEAM

| Termo | Definição canônica |
| --- | --- |
| Administrador | Usuário autorizado a acessar o dashboard, configurar o remetente, criar campanhas e acompanhar resultados. |
| Campanha educativa | Conjunto versionado de assunto, layout, destinatários, objetivo e eventos de uma ação de conscientização autorizada. |
| Correlação | Identificador único associado a uma mensagem ou convite para relacionar envio e interação sem armazenar credenciais. |
| Destinatário | Endereço de e-mail corporativo incluído em uma campanha ou convite de treinamento. |
| Domínio autorizado | Domínio permitido pela allowlist para receber mensagens do sistema. |
| Evento de campanha | Registro mínimo de `sent`, `click` ou `orientation_complete`. |
| Grupo | Coleção nomeada de pessoas usada para organizar o público de uma campanha. |
| Layout educativo | Modelo de conteúdo da mensagem, com logo, chamada, texto e botão, sem campos de senha ou coleta de credenciais. |
| Orientação | Página educativa aberta depois da interação com uma campanha. |
| Pessoa | Registro local de nome, e-mail, setor e grupo de um participante. |
| Rascunho | Campanha criada e editável que ainda não foi enviada. |
| Remetente de campanha | Configuração de endereço, nome, Reply-To e servidor SMTP usado pelo envio. |
| SMTP AUTH | Autenticação do cliente perante o servidor SMTP corporativo. |
| STARTTLS | Modo de criptografia que inicia uma sessão SMTP e a promove para TLS. |
| Treinamento | Curso com módulos, objetivos, avaliação e eventos de convite, abertura e conclusão. |
| Allowlist | Lista positiva de domínios que limita os destinatários válidos. |
| LGPD | Lei Geral de Proteção de Dados Pessoais, usada aqui como referência para finalidade, minimização, acesso e retenção. |

## Termos que não devem ser usados como sinônimos

- `Clique` não significa conclusão da orientação.
- `Aberto` não significa concluído.
- `Encaminhado` não é um evento confiavelmente identificável pelo sistema atual.
- `Campanha enviada` não significa que todos os destinatários visualizaram a mensagem.
